# 示例 3：Node CLI 工具

## 直接粘这句给 DSH

```
写一个 Node.js CLI 工具 `loggrep`：读日志文件、按级别/关键字/时间范围过滤、
支持 --json 输出、彩色高亮、参数校验和 help 文本，至少给出 3 个测试用例。
```

## 流水线会怎么跑（预期行为）

1. **拆模块**：`parse`（参数解析/校验）、`filter`（过滤逻辑）、`format`（彩色输出/JSON）。
2. **L2** 写完整文件（`cli.js`、`lib/*.js`、`test/*.test.js`）。
3. **L3 碎活**：`parseLevel(str)`、`parseTimeRange(a,b)`、`colorize(text,level)` 等纯函数——正好是一行一个的小函数，本地模型最擅长。
4. **质量门**：断言示例 `parseLevel('WARN')==='warn'`、`parseTimeRange('2024-01-01','2024-01-02')` 边界检查。
5. **里程碑**：`CLI 可运行`（help 文本 + 基础过滤）→ `功能完整`（时间范围/JSON/颜色）。

## 为什么适合流水线

CLI 工具天然模块化、验收标准可以写成函数级断言、几乎不需要 UI 联调——是「几乎零返工」的产线甜点区。

---

> 示例只是演示产线如何拆活。真实使用不需要照抄模块名，主 agent 会按你的项目自然接缝来拆。
